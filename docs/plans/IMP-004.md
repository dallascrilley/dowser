## Implementation Steps

1. Create scripts/create-skill.ts as interactive CLI
2. Prompt for: name (kebab-case), display name, category, short description
3. Generate SKILL.md with valid frontmatter from template
4. Create references/ and examples/ subdirectories if requested
5. Add skill to skill-rules.json with default keywords from name tokens
6. Output path to created skill and next steps

## Acceptance Criteria

[ ] Running `bun run scripts/create-skill.ts` prompts for skill details
