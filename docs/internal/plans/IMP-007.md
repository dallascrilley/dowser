## Search Tokens

## Implementation Steps

1. Add @opentelemetry/sdk-trace-base and @opentelemetry/exporter-trace-otlp-http dependencies
2. Create lib/tracing.ts with tracer initialization
3. Wrap key functions in spans: discoverSkills, scoreSkillsWithFuse, scoreSkillsWithTfIdf, scoreSkillFromRules
4. Add attributes: query length, skill count, cache hit/miss, top score
5. Export to local Jaeger/console when OTEL_EXPORTER_OTLP_ENDPOINT is set

## Acceptance Criteria

[ ] With OTEL_EXPORTER_OTLP_ENDPOINT set, traces appear in Jaeger UI
[ ] Spans show timing breakdown: discovery, fuzzy scoring, TF-IDF scoring, rules scoring
[ ] Cache hits/misses visible as span attributes
[ ] No performance regression when tracing disabled (default)

## Test Plan

- Unit test: Spans created with correct names and attributes
- Integration test: Traces export to console when configured
- Performance test: <5ms overhead when tracing enabled

## Risk Mitigation
