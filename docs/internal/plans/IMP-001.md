## Implementation Steps

1. Add `effectiveness` field to SkillMetrics interface: Record<string, {suggestions: number, activations: number, rate: number}>
2. Calculate activation rate on each recordSkillActivation call: activations[skill] / suggestions[skill]
3. Add --effectiveness flag to view-metrics.ts showing activation rates sorted by gap
4. Update formatSkillSuggestions to deprioritize skills with <5% activation rate after 50+ suggestions
5. Add periodic console warning when top-suggested skill has <10% activation rate
