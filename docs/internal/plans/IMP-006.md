## Search Tokens

`additionalContext`, `SessionStart`, `hookSpecificOutput`

## Implementation Steps

1. Track session context: files read, tools used, skills activated in memory
2. Build session skill profile: { domain: 'frontend' | 'backend' | 'infra', stack: string[], patterns: string[] }
3. Weight skill scores by session profile match (e.g., frontend session boosts React skills)
4. Add 'related skills' suggestions when a skill is activated
5. Persist session profile to temp file for resumption

## Acceptance Criteria

[ ] After reading React files, React-related skills rank higher for ambiguous queries
[ ] Activating one skill suggests related skills in output
[ ] Session profile visible in debug mode
[ ] Profile persists across hook invocations within session

## Test Plan

- Unit test: Session profile builds correctly from mock file reads
- Integration test: Skill rankings change based on session context
- A/B test: Compare suggestion relevance with/without session awareness

## Risk Mitigation

Feature flag SKILL_SESSION_AWARE=1 to enable; default off initially
