## Implementation Steps

1. Create lib/skill-index.json to persist skill cache across sessions
2. On hook startup, load skill-index.json if exists and mtime < 1 hour
3. Store Fuse.js serialized index in cache for O(1) search initialization
4. Add --rebuild-index flag to force cache invalidation
5. Add cache hit/miss logging when SKILL_ANALYZER_DEBUG=1

## Acceptance Criteria

[ ] Second hook invocation within 1 hour uses cached index (visible in debug output)
[ ] Cache invalidates when any SKILL.md mtime changes
[ ] --rebuild-index flag forces fresh index build
[ ] Hook latency reduced by >30% on cache hit (measure with `time`)

## Test Plan

- Unit test: Cache loads correctly from disk
- Unit test: Cache invalidates on file change
- Performance test: Measure hook latency with and without cache

## Risk Mitigation

Stale cache fallback: if cache load fails, rebuild silently
