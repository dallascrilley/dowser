## Implementation Steps

2. Analyze top gaps from skill-metrics.json: cluster related queries, identify common themes
3. Generate SKILL.md content: frontmatter, description, when_to_use, initial content sections
4. Run generated skill through garden.sh validation
5. Create PR-ready branch with generated skill for human review
6. Add eval test case for new skill automatically
