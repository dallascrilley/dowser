# Output Format Templates

Detailed templates for creating navigable structures through ambiguous knowledge.

## Tension Map Template

Use this format to document productive disagreements:

```markdown
# Tension Map: [Topic Name]

## Core Tension

[Clear statement of the fundamental disagreement or tension]

## Position A: [Name/Label]

**Core Claim:**
[What this position asserts]

**Validity:**
[Why this position has merit - evidence, logic, context]

**Unique Insights:**
[What this viewpoint reveals that others miss]

**Applicable Contexts:**
[When/where this position might be true]

**Supporting Evidence:**
- [Evidence point 1]
- [Evidence point 2]

## Position B: [Name/Label]

**Core Claim:**
[What this position asserts]

**Validity:**
[Why this position has merit - evidence, logic, context]

**Unique Insights:**
[What this viewpoint reveals that others miss]

**Applicable Contexts:**
[When/where this position might be true]

**Supporting Evidence:**
- [Evidence point 1]
- [Evidence point 2]

## [Additional Positions as Needed]

## What Would Be Lost

**If Position A Were Adopted Exclusively:**
[Insights, perspectives, or understanding that would disappear]

**If Position B Were Adopted Exclusively:**
[Insights, perspectives, or understanding that would disappear]

## Synthesis Opportunities

[Areas where positions might complement rather than contradict]
[Potential both/and framings]
[Deeper questions the tension reveals]

## Navigation Guidance

[How to work productively with this tension rather than resolving it]
```

## Uncertainty Cartography Template

Use this format to map the boundaries of knowledge:

```markdown

## Known Territory

### High Confidence (90-100%)
- [Claim 1] - [Why we're confident]
- [Claim 2] - [Why we're confident]

### Medium Confidence (60-90%)
- [Claim 1] - [Why moderate confidence]
- [Claim 2] - [Why moderate confidence]

### Low Confidence (30-60%)
- [Claim 1] - [Why uncertain]
- [Claim 2] - [Why uncertain]

## Known Unknowns

### Answerable Questions (Awaiting Data)
- [Question 1] - [What data/research would answer this]
- [Question 2] - [What data/research would answer this]

### Difficult Questions (Fundamental Challenges)
- [Question 1] - [Why this is fundamentally difficult]
- [Question 2] - [Why this is fundamentally difficult]

### Potential Unknowables
- [Question 1] - [Why this might be impossible to know]
- [Question 2] - [Why this might be impossible to know]

## Patterns in Ignorance

### Systematic Blind Spots
[What types of questions consistently elude us and why]

### Missing Frameworks
[What conceptual tools we lack that would help]

### Methodological Limitations
[What our current methods can't address]

## Confidence Gradients

### Where Certainty Fades
[Describe the boundaries where confidence decreases]
[Map the transition zones]

### Where Disagreement Begins
[Identify topics where expert consensus breaks down]

## Strategic Importance

### Critical Uncertainties
[Unknowns that matter most for decisions/understanding]

### Lower-Priority Unknowns
[Things we don't know but can work around]

## Navigation Guidance

[How to operate effectively despite these uncertainties]
[What decisions can be made and what should wait]
```

```markdown
[What makes this logically contradictory]

[Previous attempts to resolve and why they failed]

[Why this might be inherent to the domain]

## What It Reveals

[What this paradox shows about limits of our thinking]

[What this teaches us about the subject matter]

[Meta-insights about how we know things]

## Historical Context

[When and how this paradox was identified]

[How understanding has developed over time]

## Related Paradoxes

- [Paradox 2] - [Relationship]

## Further Reading

- [Resource 1]
- [Resource 2]
```

## Quick Reference: Which Format to Use

**Use Tension Map when:**
- Multiple valid viewpoints exist
- Different sources fundamentally disagree
- Resolution would lose valuable insights

**Use Uncertainty Cartography when:**
- Mapping what we don't know is critical
- Confidence levels vary significantly
- Blind spots need to be identified

**Use Paradox Preservation when:**
- Apparent contradictions reveal deeper truths
- Resolution attempts consistently fail
- The paradox itself is informative

**Use Ambiguity Index when:**
- Decision-making under uncertainty is needed
- Multiple interpretations coexist
- Practical navigation is the priority

## Combining Formats

For complex situations, you can combine formats:
1. Start with Uncertainty Cartography to map the landscape
2. Add Tension Maps for major disagreements
3. Include Paradox Preservation for key contradictions
4. Finish with Ambiguity Index for actionable guidance
