KEY FEATURES IMPLEMENTATION
============================

1. CSV Import with Validation
   File: bulk_import.py, BulkImporter class
   - load_records()          - Parse CSV
   - validate_csv_headers()  - Check column names
   - _validate_record()      - Validate field values
   - Entity-specific validation methods

2. UPSERT Duplicate Detection
   File: bulk_import.py, CopperCRMClient class
   - find_duplicate()        - Search existing records
   - upsert_record()         - Create or update based on duplicate ID
   - _find_lead()            - Search by email
   - _find_person()          - Search by email
   - _find_company()         - Search by name
   - _find_opportunity()     - Search by name

3. Batch Processing (10 records)
   File: bulk_import.py, BulkImporter class
   - import_batch()          - Process batch of records
   - Loop through valid_records in BATCH_SIZE chunks
   - Update progress bar per batch

4. Rate Limiting (3 req/sec)
   File: bulk_import.py, CopperCRMClient class
   - _rate_limit()           - Enforce 3 requests/second
   - Calculated as 1/3 = 0.333 seconds between requests
   - Applied before each API call

5. Error Recovery (3 retries)
   File: bulk_import.py, BulkImporter class
   - _import_record_with_retry() - Retry loop
   - MAX_RETRIES = 3 attempts
   - RETRY_DELAY = 2 seconds between attempts
   - Tracks retry_count in ImportResult

6. Progress Bar
   File: bulk_import.py, run() method
   - Uses rich.progress.Progress
   - Shows spinner + bar + percentage
   - Updates with batch progress
   - Real-time status display

7. Summary Report
   File: bulk_import.py, _print_report() method
   - Total records count
   - Successful imports count
   - Duplicates updated count
   - Failed records count
   - Success rate percentage
   - Failed records table with errors


ENTITY TYPE CONFIGURATION
==========================

All entity types configured in ENTITY_HEADERS dict:

Leads:
  Required: name, email, company_name, title, phone
  Search key: email
  Endpoints: /leads (POST/PUT), /leads/search (POST)

People:
  Required: name, email, company_name, title
  Search key: email
  Endpoints: /people (POST/PUT), /people/search (POST)

Companies:
  Required: name, email_domain, address
  Search key: name
  Endpoints: /companies (POST/PUT), /companies/search (POST)

Opportunities:
  Required: name, primary_contact_email, monetary_value
  Search key: name
  Endpoints: /opportunities (POST/PUT), /opportunities/search (POST)


USAGE EXAMPLES
==============

Basic import (UPSERT mode):
  python bulk_import.py leads leads.csv

Create new only (skip existing):
  python bulk_import.py leads leads.csv --mode create

With explicit API key:
  python bulk_import.py leads leads.csv --api-key "key123"

Import people:
  python bulk_import.py people people.csv

Import companies:
  python bulk_import.py companies companies.csv

Import opportunities:
  python bulk_import.py opportunities deals.csv

Using environment variable:
  export COPPER_API_KEY="key123"
  python bulk_import.py leads leads.csv


CONSTANTS & CONFIGURATION
==========================

BATCH_SIZE = 10
  - Records processed per batch
  - Adjustable for larger/smaller batches

RATE_LIMIT = 3
  - Requests per second
  - 1.0 / RATE_LIMIT = minimum interval between requests

MAX_RETRIES = 3
  - Maximum attempts per failed record
  - Includes initial attempt

RETRY_DELAY = 2
  - Seconds to wait between retry attempts

ENTITY_HEADERS
  - Dict mapping entity_type to required CSV columns
  - Case-insensitive, whitespace-trimmed


PERFORMANCE METRICS
===================

Speed:
  - Batch size: 10 records
  - Rate limit: 3 req/sec (333ms per request)
  - Per record: ~400-500ms (duplicate check + import)
  - Throughput: ~100-150 records/minute
  - 1000 records: ~7-10 minutes

Memory:
  - Stream processing (no full CSV load)
  - Memory usage: O(batch_size) ≈ ~10 records
  - No memory increase with larger files

API Calls:
  - Per record (UPSERT mode): 2 calls (search + create/update)
  - Per record (CREATE mode): 1 call (create only)
  - Per batch: 10-20 calls + retries

Rate Limiting:
  - 3 requests per second = 180 per minute
  - With 2 calls per record = 90 records per minute
  - Easily adjustable via RATE_LIMIT constant

EXTENSIBILITY & CUSTOMIZATION
==============================

Add new entity type:
  1. Update ENTITY_HEADERS dict
  2. Add validation method (_validate_<type>)
  3. Add search method (_find_<type>)
  4. Update find_duplicate() router

Customize validation:
  - Extend _validate_record() method
  - Add entity-specific rules
  - Validate format, length, ranges, etc.

Adjust rate limiting:
  - Change RATE_LIMIT constant (requests/sec)
  - Change BATCH_SIZE for larger/smaller batches
  - Change MAX_RETRIES and RETRY_DELAY

Add logging:
  - Import logging module
  - Create logger instance
  - Add log statements in key methods
  - Configure log level in main()

QUICK REFERENCE
===============

Command format:
  python bulk_import.py <entity_type> <csv_file> [--mode {create,upsert}] [--api-key KEY]

Entity types:
  leads, people, companies, opportunities

Modes:
  create - Create new records only
  upsert - Update existing or create new (default)

Environment:
  COPPER_API_KEY - API key for authentication

Exit codes:
  0 - Successful completion
  1 - CSV file not found or parsing error
  2 - API key not provided
  130 - User cancellation (Ctrl+C)

Progress output:
  Real-time progress bar with percentage
  Loading message + record count
  Import status during processing

Results:
  Summary table with counts and percentages
  Failed records table with error messages
  Success rate calculation

For detailed help:
  python bulk_import.py --help
